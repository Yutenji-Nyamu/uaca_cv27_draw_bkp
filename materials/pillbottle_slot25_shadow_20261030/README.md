## 信号口径

“分散度”是学生4次不同噪声生成动作的相对分散程度，并非直接测量的概率熵。“师生距离”是同观察、同噪声下两模型14维真实动作的RMSE，坐标为模型归一化空间。两者均逐预测动作记录；实际执行前20个动作后重新观察。详见源码快照，避免改指标后仍沿用旧名。

共提交100个动作，成功提前结束后最后3个动作位置未走到。图上这3个位置用虚线；原100位置 Spearman ρ≈0.430，已到达97位置ρ≈0.434。视频244帧、控制记录2428步；动作索引与仿真步、视频帧不能直接等同。
