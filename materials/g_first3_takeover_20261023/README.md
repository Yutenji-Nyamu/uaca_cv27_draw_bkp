## 文件

- `derived/episodes.csv`：每回合实际/请求种子、成败、总/前3块接管计数、长度；可做种子配对。
- `derived/decisions.csv`：每次真实决策的当前U、是否强策略、query、动作范围、回合成败。
- `raw/batches/*/action_u_and_decisions.npz`：未降精度的逐动作U（每次预测50位置）、active/selected/before/after/offered/success_after。每个键带query编号。只有active槽是真实决策；C20时不可把后30个未执行预测位置当已执行动作。
- `raw/batches/*/{episodes,decisions,config,done,seeds,timing}.json`：原始轻量记录；`raw/summaries/`含保存的汇总与基线回合。
- `raw/{calibration,frozen-thresholds,manifest}.json`、`raw/thresholds/`：门槛来源、冻结值、模型与预算；源码快照位于`source/`，运行清单位于`runtime/`。
- `comparison_h/`：H已完成结果，单独标记，不能混入G当同一个实验。
- `provenance.json`：原始服务器路径和导出信息。视频、原图、模型权重、控制器大数组没有复制；本包面向曲线绘图，原始媒体仍留服务器。不是完整训练/仿真环境发行包。
