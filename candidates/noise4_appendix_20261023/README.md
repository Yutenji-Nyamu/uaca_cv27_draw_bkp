## 帧与曲线对应

- `selection.json` 保存动作编号、U值、策略查询、实际活动手、视频帧号、视频时间、原选点、本轮选点和解释文字。
- 每个动作在同一策略查询内，按实际活动手的 `*_h_projection` 选取最近视频帧。这是已保存的几何投影对应，所选48帧最大偏差为 0.821 个动作位置；具体值逐帧保存在 JSON。
- `data/Nxx.json` 保留源曲线数组；`frames/Nxx/` 保存本轮已选与邻近候选帧。完整视频已有公开备份：[源仓库](https://github.com/Yutenji-Nyamu/tts_consistency_fig)。
